# Project audit, 2026-11-25

Method and honest limits: compiler output (0 errors, 8 deprecation warnings), the full Android lint list (0 errors, 81 warnings, published by CI for the first time this round), the 1058 core tests, pattern scans of all 189 main source files (catch-alls in coroutine code, unbounded reads, key placement, `!!`, GlobalScope/runBlocking, receivers, PendingIntent flags, permissions vs API use), and a manual read of the highest-risk files (hands-free service, receivers, wake scheduler, key store, confirmation gate, HTTP transport, theme, start-up). **Not covered:** a line-by-line read of every file, and anything that only shows on a real phone. The app has never been run on a phone.
